# Product Docs

These files are the living product contract for `dnd_kit`.

- `overview.md`
- `package-architecture.md`
- `api-principles.md`
- `release-roadmap.md`

`SPEC.md` and `SPEC_JASPR.md` are retained as seed inputs and historical
references. New work should update these smaller product docs and executable
proof instead of extending the monolithic specs. Use one execution plan when
complex work needs durable memory, and add a decision record only when future
work must inherit a lasting choice. Existing story packets remain delivery
history rather than a mandatory lifecycle for new work.
